# ilumr-resources
A repository of miscellaneous resources for the *ilumr* mini benchtop MRI system. Many of the resources relate to posts from our [blog](https://www.resonint.com/blog).

## [3D Printing Files](https://github.com/Resonint/ilumr-resources/tree/main/3D-printing-files)
Printable STL files created using data aquired on *ilumr*.

## [K-Space Data](https://github.com/Resonint/ilumr-resources/tree/main/kspace_data)
Sample k-space data collected on *ilumr*.

## [Notebooks](https://github.com/Resonint/ilumr-resources/tree/main/notebooks)
A collection of Jupyter notebooks and accompanying python pulse sequences for:
- [Diffusion Imaging](https://github.com/Resonint/ilumr-resources/tree/main/notebooks/diffusion_imaging)
- [Flow Imaging](https://github.com/Resonint/ilumr-resources/tree/main/notebooks/flow_imaging)
- [1D, 2D, 3D Imaging](https://github.com/Resonint/ilumr-resources/tree/main/notebooks/imaging)
- [Music](https://github.com/Resonint/ilumr-resources/tree/main/notebooks/music)
- [Relaxometry](https://github.com/Resonint/ilumr-resources/tree/main/notebooks/relaxometry)
- [Utilities](https://github.com/Resonint/ilumr-resources/tree/main/notebooks/utilities)
- [matipo Experiment Library (BaseExperiment) Tutorials](https://github.com/Resonint/ilumr-resources/tree/main/notebooks/experiment_library_tutorials)
